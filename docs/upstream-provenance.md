# Upstream provenance

This repository began with selected files from the [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template) at commit [`cb740b656d7a0a6c5e12c7bf8e50343ec94ee9c7`](https://github.com/fastapi/full-stack-fastapi-template/tree/cb740b656d7a0a6c5e12c7bf8e50343ec94ee9c7).

The imported baseline includes the `backend/`, `frontend/`, `packages/`, and `scripts/` source trees plus its dependency lockfiles, container definitions for local development, and root development configuration. The upstream Git history is not part of this repository and is not counted toward this project's new-commit target.

The upstream maintainer workflows, release automation, deployment workflows, project-management configuration, template-agent files, editor settings, FastAPI Cloud configuration, tracked development environment file, template screenshots, and upstream deployment/release documentation were intentionally excluded. This repository supplies its own CI, deployment, and operating documentation.
